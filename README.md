# Эрээнээс MGL карго — Брэндбүүк 2.0 (шилжсэн)

Брэндбүүк **[Amgalan88/ereeneesmglcargo](https://github.com/Amgalan88/ereeneesmglcargo)** репо руу бүрэн шилжиж, **https://www.ereeneesmglcargo.mn/brandbook** хаягаар ажиллаж байна. Цаашид бүх засварыг тэр репод хийнэ.

- `/brandbook` — нүүр
- `/brandbook/guide` — Үзэх хэсэг
- `/brandbook/studio` — Ажиллах хэсэг (QR, PDF)

Энэ репо archive хийгдсэн. Үлдсэн цорын ганц үүрэг нь `brandbook20.vercel.app` хаягийг шинэ хаяг руу 308-аар чиглүүлэх (`vercel.json`). Хуучин кодыг git түүхээс (`daf3220` commit) харж болно. Vercel project-ийг устгавал чиглүүлэлт зогсоно.

The brandbook moved to the `ereeneesmglcargo` repo; this repo only serves redirects from brandbook20.vercel.app.
